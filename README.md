# Pretty Little Baby 👶

It is a baby simulation where you can feed the baby and do more things.

<img width="1350" height="584" alt="Screenshot 2026-08-26 055551" src="https://github.com/user-attachments/assets/f1f9d79b-1aea-4785-b177-11978a8cf395" />

Made with HTML, JavaScript, and CSS.

Features
1. Cute Baby with one tooth and waving hands!
2. Toggle for  gender change, it automatically changes clothes, shoes, hair accessories and more.
3. Feeder to feed the baby
4. Pacifier to soothe the baby
5. Rattle for the baby to play
6. Audio for laughs and giggles

How to play!
1. When you click the baby, you will hear a giggle sound and see some hearts.
2. You can change the baby's gender.
3. There are also some options like a feeder, pacifier, and rattle. When you drag this item to the baby's mouth, you will hear the baby laugh, and if you do not drag the item to the mouth, it will be missed
